# Knowledge base (synthetic)

These documents describe **Contoso Home Services**, a fictional home automation
managed service provider. All names, prices, policies and URLs are invented for
this demo. `contoso-home.example` uses the reserved `.example` domain.

The agent answers customer questions from these documents only.

| File | Topic |
|---|---|
| `service-plans.md` | Plans, prices, add-ons, installation |
| `alarm-monitoring.md` | Professional monitoring, passcodes, test mode, false alarms |
| `troubleshooting-hub-offline.md` | Hub status lights and offline troubleshooting |
| `troubleshooting-device-pairing.md` | Adding and re-pairing devices (Z-Wave, Zigbee, Matter, Wi-Fi) |
| `outages-and-service-status.md` | Status page, outage notices, service credits, maintenance |
| `support-hours-and-escalation.md` | Support hours, callbacks, when a human takes over |
| `billing-and-cancellation.md` | Billing, late payments, cancellation, refunds |
| `video-and-privacy.md` | Camera recording, retention, who can see footage |
